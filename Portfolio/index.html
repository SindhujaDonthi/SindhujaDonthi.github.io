Fashion Assistant — Multimodal RAG

A cross-modal retrieval system that understands fashion products through both images and text. CLIP aligns images and queries in a shared embedding space, ChromaDB powers cosine-similarity search over 4K products, and LLaVA-1.5-7B generates grounded, natural-language recommendations.

Agentic RAG System

An autonomous question-answering agent built on the ReAct (Reason + Act) pattern. The LLM decides which of five tools to use — document search, web search, Wikipedia, calculator, summarizer — looping through reason→act→observe until it produces a complete, grounded answer.

DeepGPD

A deep-learning framework for modeling rare geospatio-temporal extreme events. It fuses CNNs for spatial dependencies with Extreme Value Theory and DeepSets for variable-length time series, validated using Mean Residual Life plots and Negative Log-Likelihood on NOAA GHCN climate data.
